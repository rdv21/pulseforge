# PulseForge Changes — 2026-08-03

## Ship-Readiness Fixes (Session 1)

### 1. Noise Suppression: RNNoise → SpeexDSP
**Files:** `backend/dsp.py`, `backend/native_chain.py`, `main.py`, `backend/config.py`, `qml/MicSettingsWindow.qml`

- New `SpeexNoiseProcessor` class in `dsp.py` using libspeexdsp via ctypes
- `speex_preprocess_state_init(480, 48000)` + `speex_preprocess_run()` (int16 in-place)
- Intensity 0-100% → 0 to -60dB continuous suppression (no robotic artifacts)
- VAD disabled (gate handles that), denoise enabled
- `native_chain.py`: swapped `self.rnnoise` → `self.noise = SpeexNoiseProcessor()`
- Removed pre-gain/post-atten hack (RNNoise needed +24dB, speex doesn't)
- `main.py`: `setNoiseIntensity()` now passes `intensity * 100.0` to `set_noise(intensity=)`
- Config default: 50% intensity (was 80% for RNNoise's vad_threshold)
- QML: title "Noise Cancellation" (was "AI Noise Cancellation"), default slider 50%
- `RNNoiseProcessor` kept as legacy fallback class

### 2. Auto-Detect Any Input Device
**Files:** `backend/native_chain.py`, `main.py`

- `_redirect_capture()` rewritten: no more hardcoded HiFi__Mic2 preference
- Auto-detection priority: configured device → any non-monitor/non-virtual hardware source → first available
- New `_configured_input_device` field on NativeMicChain
- New `set_input_device(source_name)` method — sets configured device + redirects
- `main.py` `_start_mic_chain()` calls `set_input_device(saved_input)` on startup
- `setInputDevice()` slot calls `set_input_device()` instead of just `redirect_capture()`

### 3. Latency Optimization
**Files:** `backend/native_chain.py`

- `PIPEWIRE_LATENCY=480/48000` env var set on all pw-cat spawns
- Applied to: `start()`, `_restart_capture()`, `_restart_playback()`, `redirect_capture()` restart path
- Combined with existing `--latency 480` flag for double enforcement

### 4. Volume Ramping (Fix Popping)
**Files:** `backend/pipewire_ctl.py`, `main.py`

- `create_loopback()` now accepts `initial_volume=0.0`, `ramp_to=None`, `ramp_ms=150`
- New `_set_loopback_initial_volume()` — sets volume on freshly created loopback sink-input
- New `_ramp_loopback_volume()` — background thread, 20ms steps
- New `remove_loopback_ramped(mod_idx, ramp_ms=100)` — ramp to 0 before unload
- `setChannelStream` in main.py: connect uses `ramp_to=stream_vol`, disconnect uses `remove_loopback_ramped()`

### 5. Stream VU = Pre-Stream-Fader
**Files:** `main.py`

- Stream VU now shows raw `peak` (signal available to stream, before stream fader)
- Main VU still shows `peak * main_vol` (what leaves main mix)
- Removed `stream_vol` from stream VU calculation

### 6. Fader Sync (Poll-Based)
**Files:** `main.py`, `qml/Main.qml`, `qml/components/ChannelStrip.qml`

- New `faderSynced(str, float)` signal on PulseForgeBridge
- `_sync_faders()` runs every 2s via QTimer
- Reads pactl sink-inputs, matches `pulse.module.id` to channel loopback mods
- If volume differs >2% from saved config, emits `faderSynced(channel, volume)`
- QML `onFaderSynced` calls `ChannelStrip.setExternalVolume(volume)`
- `setExternalVolume()` respects `mainFaderDragging` (won't fight user)
- New `channelName` property on ChannelStrip (lowercase, for backend matching)

## Session 2: Ship-Readiness + GitHub Prep

### Error Surfacing
**Files:** `main.py`, `qml/Main.qml`

- New `statusMessage(str)` and `errorOccurred(str)` signals on PulseForgeBridge
- Status toast bar at bottom of Main.qml:
  - Auto-hides after 4s
  - Blue for info, red for errors
  - Animated height transition
- Error checks at key failure points:
  - Virtual sink creation failure → "Failed to create {channel} audio channel"
  - Gaming sink missing → "Failed to create master audio sink"
  - Mic chain startup failure → "Mic processing chain failed to start"
- Status message on success: "PulseForge ready"

### First-Run Auto-Detect
**Files:** `backend/config.py`

- `_auto_detect_devices(cfg)` called on first run (no config file exists)
- Output: scans pactl sinks, prefers alsa_output with hdmi-stereo/analog-stereo
- Input: scans pactl sources, prefers USB mics, skips monitors/virtual
- Stream: defaults to same as output
- Saves detected config immediately

### Process Cleanup
**Files:** `main.py`, `backend/process_manager.py`

- Replaced both `pkill -9 -f pw-cat.*pulseforge` calls with `get_manager().cleanup_orphans()`
- ProcessManager orphan cleanup now handles:
  - `pw-cat.*pulseforge` (native chain processes)
  - `pipewire -c filter-chain` (legacy filter-chain)
- SIGTERM → 0.5s wait → SIGKILL survivors (was 1s, faster)
- Skips processes already tracked by ProcessManager
